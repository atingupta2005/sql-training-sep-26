# Vastpro SQL - Course Content

| Session   | Topics |
|-----------|--------|
| Session 1 | Relational model, tables/keys, SELECT, WHERE, LIKE, NULL, CASE |
| Session 2 | INNER JOIN, LEFT JOIN, GROUP BY, HAVING, aggregates |
| Session 3 | Subqueries, CTEs (`WITH`), window functions |
| Session 4 | Indexes, `EXPLAIN`, sargable filters |
| Session 5 | End-to-end case study on `training`, plus reuse of LEFT JOIN / HAVING, CTE, and window functions |


All labs use MySQL database **`training`** (names like `training.customers`).

Each lab includes short **Quiz** links after major topics. Use the login ID your trainer provided; every student must attempt each quiz.
